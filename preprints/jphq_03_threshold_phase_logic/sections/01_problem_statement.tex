\section{Problem statement (frozen)}
\label{sec:problem}

\paragraph{Frozen question (Q3).}
Whether socio-technical enterprises exhibit threshold-induced phase transitions
that are structurally analogous, in a strictly diagnostic sense, to those
observed in physical continua.

\paragraph{Scope and constraints.}
This paper introduces no new primitives and does not reinterpret, extend, or
modify the Ontology of Continua (OC Core) or the executable specification
ETS.K\_EA.v1.1. All symbols, predicates, relations, and precedence rules are used
exactly as defined in these sources. The analysis is strictly non-prescriptive:
phase identification is formally separated from any notion of intervention,
control, governance, steering, or optimization. No continuity of enterprise
evolution is assumed, no dynamical law is postulated, and no objective function
is posed.

\paragraph{Analytical plan.}
The argument proceeds as follows. We (i) fix the formal setting using OC Core and
ETS.K\_EA.v1.1 only; (ii) define enterprise phases as $\Theta$-induced partitions
of the admissible state region $\Omega(K_{EA})$; (iii) state purely diagnostic
propositions concerning discontinuous changes in phase classification and
admissible reachability under threshold crossings; and (iv) specify explicit
falsifiability conditions under which the proposed analogy would fail.
