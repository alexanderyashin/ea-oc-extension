\section{Formal setting (OC/ETS-only)}
\label{sec:formal}

This paper takes the Ontology of Continua (OC Core) and the executable specification
\artifact{ETS.K_EA.v1.1} as immutable inputs
(\artifact{status: executable\_closed}).
No symbols, operators, predicates, or semantics beyond those explicitly defined
in OC Core or ETS are introduced or reinterpreted.

\paragraph{Enterprise continuum.}
The enterprise is modeled as a continuum $K_{EA}$ with admissible state region
$\Omega(K_{EA})$ and boundary $\partial\Omega(K_{EA})$.
Each state $s \in \Omega(K_{EA})$ is evaluated exclusively through
ETS-defined variables and predicates.

\paragraph{Axes.}
The set of axes $A$ is fixed by ETS and grouped into the following dimensions:
\begin{itemize}
  \item \emph{Structural:} \artifact{coupling}, \artifact{modularity},
        \artifact{centralization}, \artifact{redundancy};
  \item \emph{Governance:} \artifact{decision\_latency},
        \artifact{rule\_enforceability}, \artifact{escalation\_integrity};
  \item \emph{Operations:} \artifact{delivery\_coherence},
        \artifact{incident\_recovery\_loop}, \artifact{change\_lead\_time};
  \item \emph{Resources:} \artifact{budget\_flexibility},
        \artifact{skills\_coverage}, \artifact{supplier\_dependency};
  \item \emph{Information:} \artifact{observability},
        \artifact{traceability}, \artifact{semantic\_alignment};
  \item \emph{Risk:} \artifact{risk\_visibility}, \artifact{control\_gap\_rate}.
\end{itemize}

\paragraph{Structural tension and thresholds.}
Structural tension is represented by ETS-defined components
\[
f_k \in \{f_{\text{exist}}, f_{\text{stab}}, f_{\text{inertia}},
          f_{\text{collapse}}, f_{\text{stop}}\}.
\]
Each component is mapped to a corresponding threshold
\[
\Theta_k \in \{\Theta_{\text{exist}}, \Theta_{\text{stab}},
               \Theta_{\text{inertia}}, \Theta_{\text{collapse}},
               \Theta_{\text{stop}}\}.
\]
Threshold crossings are treated strictly as logical predicates on states $s$;
no dynamical, control, or optimization interpretation is implied.

\paragraph{Cycles.}
ETS requires the presence of cycles
\[
C = \{\artifact{governance}, \artifact{value}, \artifact{reproduction},
      \artifact{finance}, \artifact{learning}\},
\]
with closure defined by graph-closed paths and recurrent patterns over the
ETS-defined time parameter $\tau$.
Cycle absence or breakage is evaluated exclusively via ETS closure rules.

\paragraph{Continuity measure.}
The continuity (viability) measure $k_{EA} \in [0,1]$ is defined by the ETS
factorization
\[
k_{EA}
= \prod \{ H_{\Omega}, S_{\text{cycles}}, S_{\text{obs}},
           S_{\text{parent}}, S_{\text{thresholds}} \},
\]
with a hard-zero condition enforced whenever $H_{\Omega}=\text{false}$.

\paragraph{Phase logic and precedence.}
ETS defines a phase logic with strict precedence ordering
\[
\texttt{STOP} \succ \texttt{COLLAPSE} \succ
\texttt{INERTIA} \succ \texttt{SUCCESS}.
\]
Phase membership is determined solely by ETS predicates and evaluated
pointwise for each $s \in \Omega(K_{EA})$.

\paragraph{Invariants and no-go constraints.}
All reasoning is constrained by ETS invariants:
\begin{itemize}
  \item \artifact{CycleInvariance};
  \item \artifact{EnergyOfTransformation};
  \item \artifact{ObservabilityInvariant};
  \item \artifact{ParentCompatibility};
  \item \artifact{TimeScaleInvariant}.
\end{itemize}
and by explicit no-go rules:
\begin{itemize}
  \item \artifact{NoFreeTransformation};
  \item \artifact{MetricSubstitution};
  \item \artifact{GovernanceSimulation};
  \item \artifact{InstantRecovery};
  \item \artifact{ExternalOverride}.
\end{itemize}

\paragraph{Scope of use.}
Within this paper, the formal setting is used exclusively for
\emph{diagnostic classification} of states and phase transitions.
No optimization objective, intervention strategy, or governance semantics
are inferred or implied.
