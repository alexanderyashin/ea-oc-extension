\section{Phase Space Construction}
\label{sec:phase-space}

\subsection{Objective of the construction}
This section defines the \emph{structural container} for constructing a minimal,
executable, geometry-only phase space over the Enterprise Continuum \(K_{EA}\).

The goal of RUN-EDHQ-02 is strictly limited to producing a reproducible
visualization of the admissible state region \(\Omega(K_{EA})\) as specified by
\texttt{ETS.K\_EA.v1.1}, without introducing any new variables, metrics, primitives,
diagnostic claims, or phase transition logic.

All coordinates, axis names, and numerical bounds referenced here are inherited
\emph{only} from KEA (PDF-0) and \texttt{ETS.K\_EA.v1.1}. No extensions are permitted
in this run.

\subsection{State representation (container)}
An enterprise state is represented as a point (or region) in the admissible
phase space defined by:
\begin{itemize}
  \item the existing state descriptors of \(K_{EA}\),
  \item the admissible configuration set \(\Omega(K_{EA})\) as specified by the ETS,
  \item explicit boundary conditions given by the ETS domain constraints.
\end{itemize}

This subsection intentionally omits any semantic interpretation, diagnostics,
or claims about realizability beyond the explicit ETS constraints. It exists solely
to anchor executable demonstrations to a stable formal slot.

\subsection{Admissible regions and boundaries}
The phase space is partitioned into admissible and non-admissible regions according
to constraints already defined in the immutable sources (KEA, ETS).
Boundary surfaces are treated as formal \emph{domain boundaries} of \(\Omega(K_{EA})\),
with no additional assumptions about smoothness, convexity, continuity, or optimality
beyond what is explicitly stated in the underlying specification.

\subsection{Observability and projection (reserved slot)}
Observed enterprise signals (as defined in the immutable sources) may be mapped into
the phase space by projection rules defined elsewhere. This document does not define
any new projection operators; it only reserves the structural location where such
projections may be referenced.

\subsection{Executable minimal phase space demo (RUN-EDHQ-02)}
A minimal, reproducible, geometry-only demonstration is implemented as a Python script:
\begin{itemize}
  \item \texttt{src/pdf1/phase\_space\_demo.py}
\end{itemize}
which loads \texttt{ETS.K\_EA.v1.1}, extracts axis names and their numerical bounds
as given by the ETS, selects a deterministic 2D projection (by a fixed rule implemented
in the script), and generates a single phase-space figure representing the admissible
region \(\Omega(K_{EA})\) under those bounds.

All run parameters (seed, grid size, axis ranges, script hash, and produced artifacts)
are captured in:
\begin{itemize}
  \item \texttt{results/pdf1/phase\_space\_demo/run\_manifest.json}
\end{itemize}
