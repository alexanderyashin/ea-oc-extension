\begin{abstract}
OPS-2A specifies the scope-locked identity of the OPS-2 toolkit as a diagnostic-only
tooling layer with terminal STOP semantics. It consolidates explicit non-claims and
a misuse matrix that defines rejection patterns and STOP-triggering classes.
No prescriptive, recovery, optimization, or control semantics are permitted.
\end{abstract}
