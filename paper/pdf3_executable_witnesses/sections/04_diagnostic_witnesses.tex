\section{Diagnostic Witnesses (Non-Executable)}

This section specifies a small canonical registry set of \emph{diagnostic witness
labels} used for closure bookkeeping in PDF-3. Each witness is defined at a purely
formal, non-executable, and referential level.

\textbf{Scope constraints (hard).}
All semantics are inherited \emph{without modification} from the frozen upstream
artifacts: PDF-0 (KEA Whitepaper), PDF-1 (Executable Demonstration Artifact), and
PDF-2 (Structural Diagnosability \& Phase Logic). No new predicates, thresholds,
metrics, formal conditions, or diagrams are introduced in this section.

\textbf{Epistemic stance.}
All witnesses are strictly \textbf{diagnostic-only}, \textbf{non-optimizing}, and
\textbf{non-prescriptive}. They do not imply control, remediation, intervention,
optimization, or evaluation beyond inherited diagnostic classification.

\subsection{Witness registration principle (purely inherited)}

A witness label W\textsubscript{X} is \emph{registrable} in PDF-3 if and only if an
upstream inherited evaluation (as defined in PDF-1/2) yields the corresponding
diagnostic class X. PDF-3 does not define, implement, or execute the evaluation;
it only records the closure label under the frozen semantics.

\subsection{Witness W\_S: SUCCESS}

\textbf{Purpose (diagnostic role).}
Registers that the evaluated configuration is classified as SUCCESS under inherited
semantics.

\textbf{Inputs (conceptual; non-executable).}
A phase-space configuration admissible under the frozen definitions of PDF-1,
evaluated via the phase logic of PDF-2.

\textbf{Expected diagnostic classification.}
SUCCESS (as a label under inherited semantics).

\textbf{Termination condition.}
Terminates once SUCCESS classification is registered under continued diagnosability
(i.e., without triggering STOP).

\textbf{Refutation / falsifiability (inherited).}
W\_S is refuted if the inherited classifier does not yield SUCCESS for the referenced
configuration, or if STOP is triggered for that configuration during the attempted
registration under the frozen semantics.

\subsection{Witness W\_I: INERTIA}

\textbf{Purpose (diagnostic role).}
Registers that the evaluated configuration is classified as INERTIA under inherited
semantics.

\textbf{Inputs (conceptual; non-executable).}
A phase-space configuration remaining within admissible bounds as defined in PDF-1/2,
for which the inherited classification yields INERTIA.

\textbf{Expected diagnostic classification.}
INERTIA (as a label under inherited semantics).

\textbf{Termination condition.}
Terminates upon transition (under inherited phase logic) to SUCCESS, COLLAPSE, or STOP.

\textbf{Refutation / falsifiability (inherited).}
W\_I is refuted if the inherited classifier does not yield INERTIA for the referenced
configuration (e.g., yields SUCCESS/COLLAPSE/STOP instead), or if the configuration is
not admissible under the frozen upstream constraints.

\subsection{Witness W\_C: COLLAPSE}

\textbf{Purpose (diagnostic role).}
Registers that the evaluated configuration is classified as COLLAPSE under inherited
semantics.

\textbf{Inputs (conceptual; non-executable).}
A phase-space configuration that, when evaluated using frozen PDF-1/2 semantics,
is classified as COLLAPSE.

\textbf{Expected diagnostic classification.}
COLLAPSE (as a label under inherited semantics).

\textbf{Termination condition.}
Terminates immediately upon COLLAPSE classification.

\textbf{Refutation / falsifiability (inherited).}
W\_C is refuted if the inherited classifier does not yield COLLAPSE for the referenced
configuration, or if the configuration reference cannot be evaluated under the frozen
upstream evaluation semantics.

\subsection{Witness W\_{STOP}: STOP}

\textbf{Purpose (diagnostic role).}
Registers termination of evaluation via STOP due to loss of diagnosability.

\textbf{Inputs (conceptual; non-executable).}
A phase-space configuration for which inherited diagnosability conditions from
PDF-1/2 are not met, yielding STOP.

\textbf{Expected diagnostic classification.}
STOP.

\textbf{Termination condition.}
Immediate termination upon STOP.

\textbf{STOP clause (mandatory).}
STOP is a \textbf{terminal epistemic boundary condition} of diagnosis, not a failure,
error, defect, or system state. STOP does not imply remediation, intervention, or
evaluation of quality.

\textbf{Refutation / falsifiability (inherited).}
W\_{STOP} is refuted if the inherited diagnosability conditions remain satisfied for
the referenced configuration (i.e., STOP is not yielded) under the frozen semantics.

\subsection{Non-Prescription Clause}

These witness definitions do not prescribe actions, strategies, or optimizations.
They solely register diagnostic closure under frozen semantics. Any prescriptive or
operational interpretation constitutes a category error relative to the declared
artifact class of PDF-3.
