\section{Reproducibility \& Traceability (Normative Contract)}
\label{sec:ops0_repro_trace}

\subsection{Scope and intent}
This section defines the \emph{minimal contract-level obligations}
for reproducibility and traceability of OPS-0 outputs.

It specifies \emph{declarative determinism requirements},
\emph{mandatory build anchors},
\emph{evidence labeling},
\emph{missingness and uncertainty classification},
and a \emph{traceability linkage model}
from inputs to predicates to outputs and provenance.

This section is \textbf{diagnostic-only}.
It \textbf{MUST NOT} define or imply implementations,
build pipelines, CI systems, storage layouts,
data formats, APIs, execution order,
or verification procedures.

\subsection{Determinism declaration}
\paragraph{Deterministic declaration.}
If an output declares
\texttt{determinism\_claim = deterministic},
then the following conditions \textbf{MUST} hold:

\begin{itemize}
  \item identical declared inputs
        (including ETS artefact and referenced sources)
        \textbf{MUST} yield identical output content;
  \item all provenance fields defined in
        \S\ref{sec:ops0_required_field_registry}
        \textbf{MUST} remain identical across rebuilds,
        except for \texttt{timestamp\_utc}
        and fields explicitly declared to vary;
  \item nondeterministic factors
        (randomness, timing, environment-dependent ordering)
        \textbf{MUST NOT} affect output content.
\end{itemize}

\paragraph{Non-deterministic declaration.}
If deterministic behavior cannot be declared,
the output \textbf{MUST} declare
\texttt{determinism\_claim = non-deterministic}
and \textbf{MUST} declare
\texttt{epistemic\_status} as
\texttt{partial} or \texttt{stop}, as applicable.

A non-deterministic output
\textbf{MUST NOT} be represented
as conformant with deterministic obligations.

\subsection{Build anchors (declarative)}
\paragraph{Anchor obligation.}
Every OPS-0 output \textbf{MUST} declare
the following reproducibility anchors:

\begin{itemize}
  \item the governing ETS identifier and hash
        (\texttt{ets\_id}, \texttt{ets\_hash});
  \item the producing tool or runtime name and version
        (\texttt{tool\_name}, \texttt{tool\_version});
  \item the governing OPS-0 contract identifier
        (\texttt{contract\_id});
  \item a run context identifier
        (\texttt{run\_id}).
\end{itemize}

If any required anchor is missing,
ambiguous, or undeclared,
the process \textbf{MUST} emit \textbf{STOP}
as a terminal classification outcome.

\paragraph{No silent upgrades.}
A change in \texttt{tool\_version}
\textbf{MUST NOT} be silent.
A new output instance \textbf{MUST}
declare the updated version explicitly.

If identical inputs yield different outputs
across different tool versions,
this is \textbf{not} a contract violation by itself,
but the difference \textbf{MUST}
be observable via declared provenance anchors.

\subsection{Evidence profile labels (declarative only)}
OPS-0 permits \emph{evidence profile labels}
as \textbf{pure declarations}.
These labels \textbf{MUST NOT}
be interpreted as verified facts
within this contract.

An output \textbf{MAY} declare
one of the following labels:

\begin{itemize}
  \item \texttt{E0} --- no external evidence referenced;
  \item \texttt{E1} --- public qualitative references only;
  \item \texttt{E2} --- public quantitative references
        (non-executable);
  \item \texttt{E3} --- executable reproduction claimed
        from public inputs;
  \item \texttt{E4} --- audited traceability pack declared
        as existing and public.
\end{itemize}

These labels are \textbf{declarative only}
and \textbf{MUST NOT}
be presented as validated, audited,
or empirically confirmed facts
unless verified outside OPS-0.

\subsection{Missingness and uncertainty classification}
\paragraph{Epistemic status declaration.}
Every OPS-0 output \textbf{MUST} declare
\texttt{epistemic\_status}
as one of:
\texttt{complete},
\texttt{partial},
or \texttt{stop}.

\paragraph{Partial outputs.}
A \texttt{partial} output \textbf{MAY}
be declared only if:

\begin{itemize}
  \item all missing, unknown,
        or unassessed elements
        are explicitly identified as such;
  \item the provenance registry
        declares \texttt{inputs\_summary}
        and all conditionally required fields;
  \item no implied completion,
        extrapolation,
        or unstated inference is asserted.
\end{itemize}

\paragraph{STOP as terminal classification.}
If any required anchor cannot be declared,
including but not limited to
ETS hash mismatch,
missing provenance fields,
or an unformable traceability chain,
the process \textbf{MUST} emit \textbf{STOP}.

STOP is terminal.
It \textbf{MUST NOT} be treated
as a recoverable error,
downgraded output,
or ``best-effort'' result
within the same output instance.

\subsection{Traceability chain (linkability requirement)}
\paragraph{Traceability obligation.}
OPS-0 outputs \textbf{MUST}
be linkable as the following
conceptual chain:

\[
\text{Inputs}
\;\rightarrow\;
\text{Predicates}
\;\rightarrow\;
\text{Outputs}
\;\rightarrow\;
\text{Provenance}.
\]

This chain defines a \emph{linkability requirement},
not an execution process or algorithm.

\paragraph{Inputs.}
Inputs \textbf{MUST}
be identifiable by stable identifiers,
not necessarily by full content,
and \textbf{MUST} include at minimum
the governing ETS artefact
and any other sources required
to interpret predicates and results.

\paragraph{Predicates.}
Where outputs are derived via predicates,
the output \textbf{MUST} declare
\texttt{predicate\_set\_id}
and \textbf{MUST NOT}
assert predicate outcomes
that cannot be linked
to declared inputs.

\paragraph{Outputs.}
Outputs \textbf{MUST}
remain diagnostic-only and
\textbf{MUST NOT}
contain prescriptive guidance,
recommendations,
or action proposals.

Any prescriptive output
constitutes a contract violation
(\S\ref{sec:ops0_conformance_tests}).

\paragraph{Provenance.}
The provenance registry
(\S\ref{sec:ops0_required_field_registry})
closes the traceability chain
by binding outputs to declared anchors
(ETS hash, tool version, run identifier,
UTC timestamp)
and to declared epistemic status.
