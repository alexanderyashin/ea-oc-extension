\section{Conformance Tests (Normative Classification Matrix)}
\label{sec:ops0_conformance_tests}

\subsection{Scope and intent}
This section defines a \textbf{normative conformance classification matrix}
for OPS-0 outputs.

The matrix specifies \emph{contractual requirements only}.
It \textbf{MUST NOT} be interpreted as:
\begin{itemize}
  \item executable test code,
  \item an implementation guide,
  \item a benchmark or metric definition,
  \item a quality assurance procedure,
  \item an example or case study.
\end{itemize}

Any engine, toolkit, or process claiming OPS-0 conformance
\textbf{MUST} satisfy all classifications defined in this section.

\subsection{Failure classifications (canonical)}
Each conformance test yields exactly one of the following
\textbf{contract-level classifications}:

\begin{itemize}
  \item \textbf{STOP} —
        terminal epistemic boundary;
        the output is invalid and the run terminates.
  \item \textbf{NO-GO} —
        contractually forbidden emission or behavior;
        the output \textbf{MUST NOT} be produced.
  \item \textbf{NON-CONFORMANT} —
        required contract surface missing, incomplete,
        inconsistent, or violated;
        the output is rejected.
\end{itemize}

These classifications are mutually exclusive
and carry no remediation or recovery semantics.

\subsection{Conformance gate}
A process, toolkit, or output claiming OPS-0 conformance
\textbf{MUST} satisfy all classifications
T-OPS0-01 through T-OPS0-10.

Any single failure results in
\textbf{rejection} of the output
as OPS-0 non-conformant.
