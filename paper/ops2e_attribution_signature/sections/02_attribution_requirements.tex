\section{Attribution Requirements}

\subsection{Purpose (Normative)}
This section defines mandatory attribution requirements for any reuse, distribution, or derivative use of the OPS-2 Toolkit standard.
It ensures persistent authorship recognition, prevents silent removal or dilution of origin, and remains legally legible without creating a license, enforcement, or compliance regime.

\subsection{Mandatory Attribution Fields (Normative)}
Any artifact that uses, references, adapts, or derives from OPS-2 must include the following attribution fields verbatim or semantically equivalent.

\paragraph{Core Attribution Block (Required).}
The following information must be present:
\begin{itemize}
  \item \textbf{Standard Name:} OPS-2 Diagnostic Toolkit
  \item \textbf{Origin:} EA-OC-EXTENSION / ESTRA
  \item \textbf{Author:} Alexander Yashin
  \item \textbf{Standard Role:} Diagnostic-only, non-prescriptive framework
  \item \textbf{Non-Endorsement Notice:} ``Use of OPS-2 does not imply endorsement, certification, or responsibility by the author or ESTRA.''
\end{itemize}
No field may be omitted.

\subsection{Placement Rules (Normative)}
Attribution must be visible and durable, according to the medium.

\paragraph{Documents / Reports / PDFs.}
The attribution block must appear in one of: front matter, appendix, or references/acknowledgements section.
It must not be hidden in metadata only.

\paragraph{Software / Tooling.}
Attribution must appear in at least one of: README or equivalent user-facing documentation, an ``About'' screen, or a top-level documentation page.
UI placement must not imply endorsement or official status.

\paragraph{Presentations / Slides.}
Attribution must appear on the title slide or the final slide.
An abbreviated form is permitted, provided all mandatory fields remain readable.

\subsection{Persistence Rules (Normative)}
Attribution must persist across redistribution, modification, partial reuse, translation, and format conversion.
Removal or obscuring of attribution constitutes non-conforming use of the standard reference.

\subsection{Minimal Attribution for Constrained Media}
Where space is severely constrained (e.g., diagrams, posters), a minimal attribution is permitted:
\begin{quote}
``Based on OPS-2 Diagnostic Toolkit (EA-OC-EXTENSION / ESTRA, A. Yashin). No endorsement implied.''
\end{quote}
This is the only allowed reduction.

\subsection{No Branding or Mark Usage (Explicit)}
Attribution does not grant permission to use names as brands, does not allow logos, seals, or ``official'' labels, and does not imply partnership or affiliation.
This section introduces no trademark logic.
